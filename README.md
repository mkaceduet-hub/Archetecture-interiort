# Antra — Architecture & Interior Design Website

A modern architecture and interior design website concept featuring a refined visual presentation for an architecture-focused brand.

## Live Demo

[View the live website](https://mkaceduet-hub.github.io/Archetecture-interiort/)

## Project Overview

This repository contains a front-end website project for an architecture and interior design studio. It demonstrates a professional digital presentation for design services and creative work.

## Technologies

- HTML5
- CSS3
- JavaScript

## Getting Started

1. Clone or download this repository.
2. Keep the included assets and supporting folders in their original locations.
3. Open `index.html` in a modern web browser.

## Project Purpose

This project demonstrates responsive website presentation and front-end development for the architecture and interior design industry.
